# arc-cross-chain-liquidity-router

Smart contracts and examples for routing stablecoin liquidity across Arc and connected chains.

## Overview
Starter for building liquidity routers that leverage Arc's strengths and CCTP for seamless stablecoin movement.

## Tech Stack
- Solidity (Arc EVM)
- CCTP
- Hardhat

## Getting Started
```bash
git clone https://github.com/Proxtox/arc-cross-chain-liquidity-router.git
cd arc-cross-chain-liquidity-router
npm install
```

## Key Files
- `contracts/LiquidityRouter.sol` - Core routing logic
